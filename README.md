# omarcuellar.co — Sitio con Astro + Docker

Sitio web estático moderno, minimalista y ultra-liviano para compartir recursos de reparación electrónica.

## 📁 Estructura

```
src/pages/
├── index.astro          (Inicio)
├── basico.astro         (Fundamentos TRC/LCD — Gratis)
├── tips.astro           (Tips de Fallas — De pago)
└── guia.astro           (Guía de uso)
```

## 🚀 Deploy

Cambios se suben con git push y Coolify redeploya automáticamente.
